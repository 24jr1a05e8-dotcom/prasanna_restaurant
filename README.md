# Prasanna Chowdary - Restaurant Bill Generator 🍔

A beginner-friendly Python + Streamlit project based on the provided Python + Streamlit Project Challenge.

## Features
- Select food items
- Select quantities
- Calculate item-wise cost
- Apply tax
- Apply discount
- Display subtotal
- Display grand total
- Download bill summary
- Responsive colorful UI
- Animations and visual effects
- No database used

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Project requirement
This project follows the challenge requirement to use Python + Streamlit and avoid a database.
